# Art Generation Prompts

Ready-to-use prompts for `ink generate`. Copy, adjust dimensions as needed.

## Style Base

All prompts should include this style suffix for consistency:
```
watercolor and ink wash style on cream parchment background (#F5EFE3), 
soft organic edges naturally fading into background, painterly texture, 
muted earth tones with burgundy and gold accents, ethereal contemplative mood,
no people or faces, no text, no logos
```

## Processing After Generation

1. **Remove background:**
   ```bash
   rembg i generated-image.png nobg-image.png
   ```

2. **Composite onto parchment (for main pages):**
   ```bash
   convert nobg-image.png -background '#F5EFE3' -flatten final-clean.png
   ```

3. **Composite onto burgundy (for nav elements):**
   ```bash
   convert nobg-image.png -background '#722F37' -flatten final-nav.png
   ```

4. **Rename following convention:**
   ```
   [theme]-[subject]-[variant].png
   ```

5. **Move to appropriate directory:**
   - Nav elements: `public/background-art-nav/`
   - Page elements: `public/background-art-clean/`
   - Scattered: `public/background-art-scatter/`
