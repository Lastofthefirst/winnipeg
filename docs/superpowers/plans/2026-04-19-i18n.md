# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add English/French static locale routing (`/en/...`, `/fr/...`) to the Winnipeg Bahá'í site.

**Architecture:** Custom TypeScript dictionary system. `getDictionary(locale)` is the single abstraction point. `[locale]/layout.tsx` calls it once and passes `nav`/`footer` strings to `RootLayout`. Each page calls it for its own strings. No external i18n library.

**Tech Stack:** Next.js 16 static export, TypeScript, custom dictionaries, `generateStaticParams`

- [ ] Create `src/i18n/getDictionary.ts`:
```ts
import type { Locale, Dictionary } from './types'
export async function getDictionary(locale: Locale): Promise<Dictionary> {
  return (await import(`./dictionaries/${locale}`)).default
}
```

- [ ] Create `src/i18n/getCmsField.ts`:
```ts
import type { Locale } from './types'
export function getCmsField(item: Record<string, unknown>, field: string, locale: Locale): string {
  return (item[`${field}_${locale}`] ?? item[`${field}_en`]) as string
}
```

import Link from 'next/link'
import { usePathname } from 'next/navigation'

  const pathname = usePathname()
  const other = locale === 'en' ? 'fr' : 'en'

    >
      {other.toUpperCase()}
    </Link>
  )
}
